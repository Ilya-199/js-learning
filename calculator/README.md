# Калькулятор стоимости сайта
Считает цену и срок разработки по типу сайта, количеству часов,
скидке и срочности. Учебный проект, написан во время изучения
JavaScript с нуля — первый месяц.
## Что умеет
- шесть типов сайтов, цены и сроки хранятся отдельно от кода
- проверка введённых часов
- скидка в процентах и наценка за срочность
- история расчётов: показывает предыдущий результат
- прайс-лист и список типов строятся из данных сами
